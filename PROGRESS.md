
# PROGRESS — Ход разработки «Точки»

## Текущий статус

Этап: реализованы SQLite и работающая авторизация с минимальными кабинетами.

Дата начала: 20.11.2026.

- `npm.cmd --prefix client run build` — успешная сборка frontend.
- `npm.cmd --prefix client run dev` — Vite запускается на порту 5173.

- `node --check` для файлов сервера и конфигурации Vite — без ошибок синтаксиса.
- `npm ls --depth=0` в обеих частях — зависимости установлены корректно.

## Известные проблемы

- Ограничение запуска Edge из предыдущего блока не повторилось: в блоке авторизации
  Playwright успешно запустил установленный Edge в фоновом режиме; интерфейс и 360 px проверены.
- PowerShell блокирует `npm.ps1`: используется `npm.cmd`, без изменения политики Windows.
- Системный кеш npm недоступен из среды разработки: зависимости установлены
  с `--cache ../.cache/npm` из папок `client/` и `server/`. Кеш исключён из Git;
  аналогичные команды из корня проекта приведены в README.md.
- Публикация и обслуживание собранного frontend сервером пока не настроены;
  для проверки API предусмотрен локальный режим разработки.

## Блок SQLite и авторизации — 20.11.2026

- Добавлены миграции и таблицы `roles`, `users`, `sessions`, `schema_migrations`.
- `npm.cmd --prefix server run setup` создаёт секрет в игнорируемом `server/.env`
  и аккаунты `student1`, `student2`, `staff` с разными вымышленными профилями.
  Пароли случайные, выводятся только при создании; здесь и в исходниках не записаны.
  Повторная подготовка не меняет пароли, секрет и существующие данные.
- Сессии сохраняются в SQLite на 8 часов с момента входа. В production cookie
  требует HTTPS (Secure); локальный HTTP использует HttpOnly и SameSite=Lax.
- Приватные API проверяют роль и владельца профиля, возвращают 401/403, не отдают
  хеши паролей и не кешируются. Добавлены ограничение попыток входа и защита от чужих сайтов.
- `npm.cmd --prefix server test` — 12 успешных тестов: миграции, хеши и соль,
  повторная подготовка, анонимный доступ, неверный пароль, валидация, три аккаунта,
  чужие профили и роли, подмена cookie, смена сессии при входе, перезапуск процесса,
  выход и отзыв сессии, истечение срока, ограничение входа и Secure в production.
- `npm.cmd --prefix client run build` — успешно.
- Playwright + установленный Edge: проверены вход и выход всех трёх аккаунтов,
  соответствующий кабинет, обновление страницы, сохранение входа после перезапуска
  backend, ошибка пароля, возврат студента со страницы сотрудника, HttpOnly cookie,
  отсутствие токенов в localStorage, ошибка сети и повторная проверка.
- При ширине 360 px нет горизонтальной прокрутки; проверен переход Tab.
  Скриншоты просмотрены. Необработанных ошибок JavaScript не обнаружено.
- Серверные и браузерные тесты используют отдельные базы в `.cache/`.
  Временный Playwright установлен туда же и не добавлен в зависимости приложения.
- README.md дополнен подготовкой, запуском, сценариями проверки и описанием хранения.
- В основной локальной базе созданы три демонстрационных пользователя; отдельно
  проверены их вход, профиль и выход со сгенерированными паролями. Проверочные сессии отозваны.
- Повторный `setup` оставил аккаунты и секрет без изменений. Git игнорирует `.env`,
  базу, файлы SQLite WAL/SHM и `.cache/`; пример `.env.example` и миграция не игнорируются.
- `node --check` для серверного кода и `git diff --check` прошли. После последней
  правки повторно успешно выполнены 12 серверных тестов и сборка React.
- Все запущенные для проверок серверы остановлены. Git-коммиты не создавались.

Ограничения: реальное размещение с HTTPS пока не проверялось; Secure проверен
