## Проверки

Git инициализирован успешно.

Проверки блока от 20.11.2026:

- Среда: Node.js 24.22.0, npm 11.19.1.
- Зависимости установлены; npm при установке сообщил о 0 известных уязвимостей.
- `npm.cmd --prefix client run build` — успешная сборка frontend.
- `npm.cmd --prefix client run dev` — Vite запускается на порту 5173.
- `npm.cmd --prefix server run dev` и `npm.cmd --prefix server start` — Express запускается на порту 3001.
- `GET http://127.0.0.1:3001/api/health` — HTTP 200, `{"status":"ok"}`.
- `GET http://127.0.0.1:5173/api/health` — HTTP 200, тот же JSON через прокси Vite.
- Стартовый HTML по адресу frontend — HTTP 200, русский язык документа.
- Неизвестный путь `/api/missing` — HTTP 404 с сообщением об ошибке.
- При остановленном backend прокси Vite возвращает HTTP 502; после перезапуска backend — снова HTTP 200.
- `node --check` для файлов сервера и конфигурации Vite — без ошибок синтаксиса.
- `npm ls --depth=0` в обеих частях — зависимости установлены корректно.
- `git check-ignore` подтверждает исключение зависимостей, сборки, `.env`, SQLite и кеша;
  файлы `package-lock.json` не исключены.
- Тестовые серверы остановлены после проверок. Git-коммиты не выполнялись.

## Известные проблемы

- Автоматический запуск Edge для проверки React-страницы не завершился:
  среда ограничивает доступ к системным ресурсам браузера, возникли ошибки
  графического процесса. Визуальная проверка, поведение статусов в браузере
  и проверка на ширине 360 px пока не подтверждены.
- PowerShell блокирует `npm.ps1`: используется `npm.cmd`, без изменения политики Windows.
- Системный кеш npm недоступен из среды разработки: зависимости установлены
  с `--cache ../.cache/npm` из папок `client/` и `server/`. Кеш исключён из Git;
  аналогичные команды из корня проекта приведены в README.md.
- Публикация и обслуживание собранного frontend сервером пока не настроены;
  для проверки API предусмотрен локальный режим разработки.
