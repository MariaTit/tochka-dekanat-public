
# PROGRESS — Ход разработки «Точки»

## Текущий статус

Этап: реализованы SQLite, авторизация, основа кабинета студента, «Расписание», «Оценки»
и подача/просмотр заявок на документы студентом, API и интерфейс обработки сотрудником (блок №6).
Подготовлены production-сборка и конфигурация Amvera Cloud. По сообщению пользователя,
приложение развёрнуто и собирается, но публичный сайт возвращает 503.
Исправление определения production через AMVERA=1 проверено локально; в облако не отправлено.

Дата начала: 20.11.2026.

Работают вход, выход, проверка серверной сессии и разделение доступа.
Пользователи и сессии сохраняются в SQLite после перезапуска сервера.
У студента работают главная страница, профиль, общая навигация и страницы будущих разделов.
Работает расписание своей группы в трёх режимах и ближайшие занятия на главной.
Работают текущие результаты, экзамены и зачёты только своего аккаунта и блок успеваемости на главной.
Работает серверный API типов документов, подачи, списка и подробностей собственных заявок.
Работает страница «Документы»: форма двух видов справок, список своих заявок и подробности.
Работает защищённый API сотрудника: все заявки, подробности, изменение статуса и отклонение с причиной.
Работает `/staff`: список с фильтрами, подробности, смена статусов и отказ с причиной.
Студент видит причину отказа в подробностях своей заявки. Уведомления ещё не реализованы.
