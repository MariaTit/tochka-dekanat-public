
# PROGRESS — Ход разработки «Точки»

## Текущий статус

Этап: реализованы SQLite, авторизация, кабинет студента, «Расписание», «Оценки»,
подача/просмотр и обработка заявок сотрудником, раздел «Уведомления», полный профиль
студента, управление расписанием и успеваемостью сотрудником (22.11.2026).
Подготовлены production-сборка и конфигурация Amvera Cloud. По последнему сообщению
пользователя от 21.11.2026 сайт работает через HTTPS, но вход student1 не проходит;
подготовлена управляемая демоинициализация. Новые блоки реализованы и проверены
только локально; облачная база не изменялась, отправка кода не выполнялась.

Дата начала: 20.11.2026.

Работают вход, выход, проверка серверной сессии и разделение доступа.
Пользователи и сессии сохраняются в SQLite после перезапуска сервера.
У студента работают главная страница, профиль, общая навигация и страницы будущих разделов.
Работает расписание своей группы в трёх режимах и ближайшие занятия на главной.
Работают текущие результаты, экзамены и зачёты только своего аккаунта и блок успеваемости на главной.
Работает серверный API типов документов, подачи, списка и подробностей собственных заявок.
Работает страница «Документы»: форма двух видов справок, список своих заявок и подробности.
Работает защищённый API сотрудника: все заявки, подробности, изменение статуса и отклонение с причиной.
Работает `/staff`: список с фильтрами, подробности, смена статусов и отказ с причиной.
Студент видит причину отказа в подробностях своей заявки.
Работают «Уведомления» и важные сообщения главной: объявления, учебные даты,
изменения/отмены занятий и статусы заявок. Прочтение сохраняется для каждого студента в SQLite.
Профили student1/student2 содержат все пять конкурсных полей из SQLite через API;
логины, пароли, роли и прежние связанные данные сохранены.
Работает `/staff/schedule`: выбор факультета, курса и группы из базы, создание,
редактирование, перенос, отмена/восстановление занятий с уведомлениями своей группе.
Работает `/staff/grades`: выбор студента и дисциплины, просмотр результатов, выставление
и изменение экзаменов, обычных/дифференцированных зачётов с персональными уведомлениями.

## Известные проблемы

- Ограничение запуска Edge из предыдущего блока не повторилось: в блоке авторизации
  Playwright успешно запустил установленный Edge в фоновом режиме; интерфейс и 360 px проверены.

- Системный кеш npm недоступен из среды разработки: зависимости установлены
  с `--cache ../.cache/npm` из папок `client/` и `server/`. Кеш исключён из Git;
  аналогичные команды из корня проекта приведены в README.md.
